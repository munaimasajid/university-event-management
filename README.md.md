## **University Event Management System**

A PHP \& MySQL based University Event Management Website for event registration, updates, and management.



#### Features

User-friendly event registration form

Event listing by categories: Music, Sports, Tech, Art, Food

Contact form for inquiries

Responsive design with modern dark theme

Admin can manage events via database

#### Technologies Used

PHP 8

MySQL

HTML5 \& CSS3

JavaScript

XAMPP (Apache + MySQL)

#### Installation

Clone this repository:git clone https://github.com/yourusername/university-event-management.git

Copy the project folder to xampp/htdocs/.

Start Apache and MySQL using XAMPP.

Create a database named users in phpMyAdmin.

Import database.sql or manually create tables:

mydata (for event registration)

contact (for contact form)

Open in browser: http://localhost/webproject/
